# SmartFlow AI
## Intelligent Traffic Signal Optimization

### Project Overview
SmartFlow AI is an educational traffic simulation that
compares fixed-time and intelligent traffic signal control.

### Objectives
- Simulate vehicle arrivals and queues.
- Compare fixed-time and AI-based signal control.
- Measure waiting time and queue length.
- Demonstrate emergency route planning using A*.
- Visualize experiment results using a dashboard.

### Technologies
- Python
- Pygame
- Streamlit
- NumPy
- Pandas
- Matplotlib
- Git and GitHub

### Installation
Create a virtual environment and install dependencies:

    python -m venv .venv
    python -m pip install -r requirements.txt

### Run the Animation

    python animation.py

### Run the Experiments

    python experiments.py

### Run the Dashboard

    streamlit run app.py

### Run Tests

    python -m unittest discover -s tests -v

### Limitations
This is a simplified four-direction educational simulation.
It does not represent a real traffic-control installation.
